## Final review hardening

The Stage-level review identified three Important integrity edge cases and added failing regressions before fixes:

1. empty/no-mandatory release policy could vacuously evaluate PASS;
2. `RequirementRepository.add()` could accept an already-`VERIFIED` requirement;
3. an existing artifact URI could be overwritten with different bytes.

RED run `32211373815` proved the first and third failures in the unit suite. The repository authority regression was added to the PostgreSQL integration suite in the same review batch. The implementation now rejects vacuous policies, requires new requirements to be `UNVERIFIED`, and makes artifact writes idempotent for identical bytes but immutable for different bytes.

Final hardened Stage 1 gate: GitHub Actions run `32211472042` — locked dependency sync PASS, Ruff PASS, unit tests PASS, Alembic migration PASS, full integration suite PASS, Pyright PASS.
